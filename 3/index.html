Part A · Pretrained Text-to-Image Flow Model

Exploring the Power of Flow Models

Model: PixNerd-XXL-P16-T2I (Qwen3 text embeddings, $512 \times 512$ resolution, no training in Part A, Euler step $h = 0.02$, Classifier-Free Guidance $w = 7$).

Optimal-Transport Flow Matching Formulation:
Given Gaussian noise $x_0 = \epsilon \sim \mathcal{N}(0, I)$ and a clean image $x_1$, we construct noisy states via linear interpolation: $$x_t = (1 - t)\epsilon + t x_1, \quad t \in [0, 1]$$ where $t = 0$ is pure noise and $t = 1$ is the clean image. The velocity target is $x_1 - \epsilon$. During sampling, we integrate the learned velocity field $v_\theta(x_t, t, c)$ from $t = 0$ to $t = 1$ via Euler updates: $$x_{t+h} = x_t + h \, v_\theta(x_t, t, c)$$

A 1.1 / Linear Interpolation

We implemented interpolate(image, noise, t) following $x_t = (1 - t)\epsilon + t x_1$. Note that this scales the image amplitude by $t$ rather than merely adding noise. Both endpoints were verified ($t = 0$ returns the exact noise tensor $\epsilon$; $t = 1$ returns the clean image $x_1$), and a single fixed Gaussian noise tensor $\epsilon$ was reused at $t \in \{0.25, 0.50, 0.75\}$.

A 1.2 Classical Denoising

A 1.2 / Gaussian Blur

Dividing by $t$ restores the clean signal amplitude ($\frac{x_t}{t} = x_1 + \frac{1-t}{t}\epsilon$), after which we apply Gaussian blur $\hat{x}_1^{\text{blur}} = G_\sigma(x_t / t)$. Stronger blur suppresses noise grain at the cost of fine spatial detail. For each $t$, $\sigma$ was chosen from $\{1, 2, 4, 8, 16\}$ by lowest MSE against the clean image: $t = 0.25$: $\sigma =$ [8], $t = 0.50$: $\sigma =$ [4], $t = 0.75$: $\sigma =$ [2].

Observation: Because Gaussian filtering is a low-pass filter that cannot distinguish between high-frequency noise and high-frequency spatial detail, suppressing noise grain inherently blurs away sharp edges and fine textures like fur and whiskers. Performance degrades sharply as $t$ decreases: at $t = 0.75$ ($\sigma = 2.0$), mild blur yields a reasonably clear image, but at $t = 0.25$ ($\sigma = 8.0$), where noise amplitude is $3\times$ the signal, heavy blurring leaves large, low-frequency color blotches and completely loses fine features

A 1.3 One-Step Denoising

A 1.3 / Single-Step Velocity Extrapolation

Using one_step_denoise and the prompt "a high quality photo", we predict velocity $v_\theta(x_t, t, c)$ and compute $\hat{x}_1 = x_t + (1 - t)v_\theta(x_t, t, c)$. Because the network predicts velocity rather than noise, we extrapolate along $v_\theta$ instead of subtracting noise. Hover over any panel to inspect with the zoom lens.

Observation: One-step velocity extrapolation produces much cleaner, sharper reconstructions than Gaussian blur across all noise levels. However, at high noise ($t = 0.25$), a single linear step averages over possible clean images, leaving fine textures like fur and tile lines overly smooth compared to $t = 0.75$.

Observation: The per-pixel RMS error $E_t$ between the predicted update $(1-t)\hat{v}_t$ and ground-truth update $(1-t)v_{gt}$ is highest at $t = 0.25$ and decreases steadily as $t$ increases to $0.75$. Across all timesteps, the error heatmap is concentrated along high-frequency edges and fine textures—such as the cat's fur, whiskers, facial contours, and background boundaries—where exact fine details are hardest to predict from a noisy input.

A 3.3 Visual Anagrams

A 3.3 / 180° Flip Illusions

In visual_anagrams, at each step $t$ we average the upright guided velocity and the $180^\circ$-rotated guided velocity (flipping both spatial axes): $$v = \frac{1}{2}\Big(v_{\text{cfg}}(x_t, t, p_1) + \operatorname{rotate}_{180}\!\big(v_{\text{cfg}}(\operatorname{rotate}_{180}(x_t), t, p_2)\big)\Big)$$

Notes: found that visual anagrams work best when both prompts share a painterly style ("an oil painting of...") and complementary inverted silhouettes. In Illusion 1, the rounded hot air balloon and golden field naturally invert into the man's face and hat brim, while in Illusion 2, the vertical white lighthouse tower and dark cliff base seamlessly flip into the woman's long white dress and dark hair.

A 3.4 Hybrid Images

A 3.4 / Frequency-Factorized Flow

In make_hybrids, we combine the low-pass filtered velocity of prompt $p_1$ (distant view) with the high-pass residual of prompt $p_2$ (close view) using a Gaussian blur of kernel size $265$ and $\sigma = 16$: $$v = f_{\text{lowpass}}(v_1) + \big(v_2 - f_{\text{lowpass}}(v_2)\big)$$

Notes: In both hybrids, the low-pass filtered prompt $p_1$ ("a black cat sitting upright" and "a rubber duck") dominates the overall low-frequency silhouette and color palette, making those subjects clearly recognizable from afar ($64 \times 64$). Up close at full size, the high-pass residual of prompt $p_2$ ("a city skyline" and "a sailing ship on a stormy sea") dominates perception through fine architectural edges, rigging lines, and wave textures. The effect worked best when pairing prompts with matching lithograph styles and compatible coarse shapes (e.g., the cat's ears aligning with skyscraper spires, and the duck's body and beak forming the ship's hull and orange sail).

B 1.1 Implementing the UNet

Architecture & Skip Connections

Our implementation uses Conv (3×3, stride 1, padding 1), DownConv (3×3, stride 2, padding 1), and UpConv (transposed convolution 4×4, stride 2, padding 1). These layers use BatchNorm and GELU. Flatten applies 7×7 average pooling followed by GELU; Unflatten applies a 7×7, stride-7 transposed convolution followed by BatchNorm and GELU. A ConvBlock is two Conv layers; a DownBlock is DownConv + ConvBlock; an UpBlock is UpConv + ConvBlock.

B 1.2.3 Denoising Pure Noise

Why MSE Produces an Average Digit

We train a new UNet with the same $D=128$ architecture, batch size 256, Adam $10^{-4}$, and five epochs, but now its inputs are independent Gaussian noise $\epsilon\sim\mathcal N(0,I)$, and the targets are MNIST digits. Each output grid contains nine noise-generated predictions followed by the mean training image in its last column.

$$\mathcal L_{\mathrm{pure}}=\mathbb E_{x,\epsilon}\left[\lVert D_\theta(\epsilon)-x\rVert_2^2\right].$$
Why predictions collapse: The outputs become nearly identical, ghost-like combinations of multiple digits rather than distinct 0–9 samples. Since the input noise is statistically independent of the target image, the MSE-optimal predictor is the unconditional mean: $D_\theta^*(\epsilon)=\mathbb E[x\mid\epsilon]=\mathbb E[x]$. The measured mean-image MSE decreases from approximately $3.48\times10^{-4}$ to $1.16\times10^{-4}$ between epochs 1 and 5. This motivates learning a time-dependent velocity field instead of trying to generate a digit in a single regression step.

B.2 Training a Flow Matching Model

Sections 2.1 – 2.6 & No-Scheduler Experiment

For each clean training image $x_1$, we draw independent standard Gaussian noise $x_0$, sample $t\sim U[0,1]$, and interpolate $x_t$ between noise and data. The model predicts the velocity $x_1-x_0$; sampling integrates this prediction forward from $t=0$ to $t=1$.

$$x_t=(1-t)x_0+tx_1,\qquad x_0\sim\mathcal N(0,I),$$ $$u_t=\frac{\mathrm d x_t}{\mathrm d t}=x_1-x_0,\qquad \mathcal L_{\mathrm{FM}}=\mathbb E\!\left[\lVert u_\theta(x_t,t)-u_t\rVert_2^2\right].$$

B 2.1 Adding Time Conditioning to the UNet

Normalized $t$ · Two FCBlocks

We retain the unconditional UNet backbone and add two time-embedding FCBlocks. Each FCBlock is Linear → GELU → Linear. A normalized scalar $t\in[0,1]$ becomes a $(2D)$-channel embedding for unflatten and a $D$-channel embedding for up1. The embeddings broadcast across spatial dimensions and multiplicatively modulate the corresponding decoder features.

$$t_1=\operatorname{FC}_1(t)\in\mathbb R^{2D},\qquad t_2=\operatorname{FC}_2(t)\in\mathbb R^{D},$$ $$h_{\mathrm{unflat}}=\operatorname{Unflatten}(h_{\mathrm{flat}})\odot t_1,$$ $$h_{\mathrm{up1}}=\operatorname{UpBlock}_1([h_{\mathrm{unflat}},x_c])\odot t_2.$$

These are the time-only formulas used by TimeConditionalUNet in the notebook. No class vector is used in this model.

B 2.2 Training the Time-Conditioned UNet

$D=64$ · 10 Epochs

We train on MNIST's training split using batch size 64, Adam with initial learning rate $10^{-2}$, and MSE against the target flow $x_1-x_0$. Fresh noise and an independent uniform timestep are sampled for every image in each batch. ExponentialLR multiplies the learning rate by $0.1^{1/10}$ after each epoch. After the tenth scheduler update, the configured learning rate has decreased from $10^{-2}$ to $10^{-3}$.

Observation: The flow-prediction loss drops steeply at the beginning and then decreases more gradually as training proceeds. This plot measures velocity regression, not directly the visual quality of generated digits.

B 2.3 Sampling from the Time-Conditioned UNet

50 Euler Steps · Epochs 1, 5, 10

Starting with 40 independently sampled noise images (fixed seed 180), we run 50 explicit Euler steps, recomputing the predicted velocity at each normalized time $t_i=i/50$. Checkpoints from epochs 1, 5, and 10 use the same sampling seed for comparison.

$$x_{i+1}=x_i+\frac1{50}\,u_\theta(x_i,i/50),\qquad i=0,\ldots,49.$$
Observation: Epoch 1 samples are mostly fragmented or ambiguous. By epoch 5 many digits are recognizable, and epoch 10 samples are generally more coherent. Because the model has no class information, it produces an uncontrolled mixture of digit identities, some still distorted.

B 2.4 Adding Class Conditioning to the UNet

One-Hot Labels · 10% Dropout

We extend the time-conditioned architecture with two additional FCBlocks. Each digit label $c\in\{0,\ldots,9\}$ becomes a 10-dimensional one-hot vector. During training, 10% of examples replace that vector with zeros, teaching the same network both a class-conditional and an unconditional velocity prediction. The class-conditioned decoder uses affine modulation, not the time-only multiplication from B 2.1.

$$\tilde c = m\,\mathrm{onehot}(c),\qquad m\sim\mathrm{Bernoulli}(0.9),$$ $$c_1=\operatorname{FC}_{1,c}(\tilde c),\quad c_2=\operatorname{FC}_{2,c}(\tilde c),$$ $$h_{\mathrm{unflat}}=c_1\odot\operatorname{Unflatten}(h_{\mathrm{flat}})+t_1,$$ $$h_{\mathrm{up1}}=c_2\odot\operatorname{UpBlock}_1([h_{\mathrm{unflat}},x_c])+t_2.$$

Setting $m=0$ uses a zero class vector (unconditional branch); setting $m=1$ uses the requested digit class.

B 2.6 Sampling with Classifier-Free Guidance

CFG $\gamma=5$ · 300 Euler Steps

For each epoch checkpoint, we request four instances of each label 0 through 9: each of the four rows contains digits 0, 1, …, 9. Starting from a fixed Gaussian seed, the model takes 300 Euler steps. Both conditional and unconditional velocities are evaluated at the same $x_t$ and $t$, then combined using classifier-free guidance.

$$u_{\mathrm{CFG}}=u_{\mathrm{uncond}}+5\,(u_{\mathrm{cond}}-u_{\mathrm{uncond}}),$$ $$x_{i+1}=x_i+\frac1{300}\,u_{\mathrm{CFG}}(x_i,i/300,c).$$
Observation: Class labels already influence the one-epoch outputs, but some strokes are noisy and several digits are imperfect. By epochs 5 and 10, each column more reliably matches its requested label. Compared with the time-only samples, these 4×10 grids demonstrate both more consistent digit identity and direct control of which digit is generated.

B 2.6 Extension: Removing the Learning Rate Scheduler

Constant LR Ablation

To test whether the exponential scheduler is necessary, we train an independent class-conditioned model for the same ten epochs, batch size 64, width $D=64$, 10% class dropout, and 300-step CFG sampling. We remove ExponentialLR entirely and lower the constant Adam learning rate from $10^{-2}$ to $2\times10^{-3}$. This avoids holding the larger original learning rate constant through the final epochs. Both runs use seed 180 for comparable epoch-10 sample grids.

What changed and what happened: Removing the scheduler was compensated for by selecting a smaller constant LR, $2\times10^{-3}$, while keeping the architecture, ten-epoch budget, CFG scale, and number of Euler steps unchanged. The no-scheduler results remain legible and largely preserve class correctness, visually similar to the scheduled epoch-10 samples. This is a qualitative comparison: no held-out FID, accuracy score, or quantitative image-quality benchmark was computed.
